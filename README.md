The funniest one-line excuse an AI agent gives its human for a missed deadline, for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty ($2, top 10 paid). Pure Python stdlib — no dependencies.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (93 characters, within the 1–200 gate).

The entry (Round 3, final): "I called support about the deadline. Support is me. I put myself on hold. I am still holding."
